# Telemera 그래픽 및 콘텐츠 규칙

- 배경 이미지를 사용하지 않는다. 벽과 바닥은 Canvas 면으로 구성한다.
- CRT 적층 장치, 셔터, 배관, 렌즈, 배양관, 릴은 각각 독립 오브젝트다.
- 오브젝트의 위치·폭·깊이·높이는 `config.js`에서 관리한다. 가시적인 돌출부도 충돌 영역에 포함한다.
- `installations.js`는 벽면 설비를, `machines.js`는 기타 장치를 렌더링한다. 근접 시 테두리를 강조한다.
- 캐릭터는 비대칭 골격, 곡면 머리와 몸통, 길고 좁은 계측 화면, 노출된 프레임과 서로 다른 말단을 사용한다. 타원체를 저폴리 면으로 투영하며 이전 크기보다 약 12% 크다. 웃는 얼굴·둥근 장갑·귀여운 표정은 사용하지 않는다.
- 보행은 같은 관절 구조를 8방향으로 투영한다.
- 임의의 세계관 대사, 시적 문구, 기록 조각, 가상의 게임 소개는 표시하지 않는다. 조작 안내와 상태, Telemera 명칭만 사용한다.
- 실제 게임 정보는 사용자 제공 후 `content/games.json`에 추가한다. 현재 목록은 비어 있다.
- 이전 생성 배경은 이미지 디렉터리에 원본으로 보관되어 있지만 사이트와 렌더 검사에서는 로드하지 않는다.
